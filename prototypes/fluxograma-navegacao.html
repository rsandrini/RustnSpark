Núcleo do loop (azul): quadro → despacho → trânsito → relatório → porto, e volta. O Porto é uma tela só, com abas. O Mapa é o hub de navegação: leva a porto, a missões e a despachar viagem. A derrota total nunca trava o jogador — resgate-auto pago (pode ficar negativo) ou aguardar resgate. O admin é uma árvore rasa a partir do dashboard; o inspetor puxa o replay via MissionLog. Tutorial guiado vive DENTRO das telas reais (estado guiado), não como tela separada.
