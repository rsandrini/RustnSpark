# Slice 1.4: the map as a star chart

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. Commit on `develop`, one commit per task.

**Goal:** the sector map reads as a chart you play on: faction territories as soft areas, the places the ship can reach with the fuel it has, an animated planned route, and a bottom sheet for the selected place with "Plan trip". The number on each place becomes the pilots anchored there (TODO item 7), and the permanent list of 29 place cards stops being the main way in.

**Architecture:** all new map knowledge is in small pure modules (`territories.ts`, `reach.ts`) over data the page already has (`WorldResponse` locations with `factionId`, `x`, `y`, `pilotCount`; routes with `distance`; the ship sheet's `autonomy`, `fuelUse`, current fuel). `map.page.tsx` (1028 lines, already big) gets new SVG layers as small components in new files rather than more inline JSX. No server change.

**Tech Stack:** React + Vite, SVG, react-i18next, Vitest + Testing Library, Playwright. Kit from slices 1.1 to 1.3 (`RiskPips`, `BlockerChip`, `IconTabs`, `Tooltip`, `GiverBadge`/`FactionBadge`).

**Spec:** `docs/design/game-ui-v0.2-plan.md` section 4 (Map) and phase 4; mockup `docs/design/game-ui-v0.2/mockups/4-map.png`; TODO `docs/TODO_v0.1.5.md` item 7.

## Review Focus

- A faction with a single place (a territory of radius 0): draws a minimum-radius area, not nothing and not a crash. Independent places (no faction) draw no territory.
- Two territories overlapping (as in the mockup): both stay readable; labels do not collide at zoom 1.
- A ship with no fuel use (pure ion, `fuelUse` 0, range unlimited): the range layer says "unlimited" and highlights everything, never divides by zero.
- A ship in flight or without a ship: no range layer, no crash; the sheet still opens for a place.
- A place that is only reachable through an unreachable one (the route graph): reachable means a path whose total distance fits the budget.
- Zoomed in far: labels and territories keep a sane size (they scale with the view or stay fixed on screen consistently).
- A place with 0 pilots shows no badge (as today with 0 missions); a place with 100+ pilots shows a compact number.
- pt-BR faction and place names are long: the territory label and the sheet title truncate, never overlap the controls.

### Task 1: territories (pure)

**Files:** create `territories.ts`, `territories.spec.ts`.

**Interfaces:**
- Consumes: `WorldLocation` (`apps/web/src/api/generated`): `id`, `x`, `y`, `factionId` (the independent/none value: check how `factions.independent` / `factionId` is represented, e.g. empty or `'independent'`).
- Produces: `interface Territory { factionId: string; cx: number; cy: number; radius: number; placeIds: string[] }` and `territoriesOf(locations: readonly WorldLocation[], opts?: { pad?: number; minRadius?: number }): Territory[]`. Centre = centroid of the faction's places; radius = largest distance from the centroid to a place + `pad` (default 40 map units) but not under `minRadius` (default 60). Independent places are excluded. Output sorted by faction id (stable draw order).

### Task 2: reach (pure)

**Files:** create `reach.ts`, `reach.spec.ts`.

**Interfaces:**
- Consumes: `WorldResponse['routes']` (`nodeAId`, `nodeBId`, `distance`).
- Produces: `reachableWithin(routes, originId: string, budget: number): Map<string, number>` (place id -> cheapest route distance from the origin, only places with distance <= budget, origin = 0; Dijkstra over the undirected graph) and `rangeBudget(input: { autonomy: number; fuelUse: number; fuelHave: number; fuelCap: number }): number | 'unlimited'` = `'unlimited'` when `fuelUse <= 0`, else `autonomy * (fuelHave / fuelCap)` (autonomy is the full-tank route distance; guard `fuelCap <= 0` -> 0).

- [ ] **Step 1: Failing tests:** a chain A-B-C with distances 10, 20 and budget 25 reaches A, B only; budget 30 reaches C; a shorter two-hop path beats a long direct route; an unreachable island is absent; origin always present with 0; `rangeBudget` for half a tank is half the autonomy; `fuelUse` 0 -> 'unlimited'; `fuelCap` 0 -> 0.
- [ ] **Step 2: Run:** FAIL. **Step 3: Implement.** **Step 4: Run:** PASS.
- [ ] **Step 5: Commit** `feat(ui): which places the fuel on board can reach (pure)`.
